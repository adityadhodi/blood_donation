ABOUT OUR PROJECT

About LifeDrop

LifeDrop is a browser-based blood donation awareness and donor directory application developed as a college project. It demonstrates how simple web technologies can help organize donor information and sample blood requests in one interface.

🎯

Our Objective

The main objective of LifeDrop is to create a simple, user-friendly interface for donor registration, searching demo donor records, recording sample blood requests, and displaying basic statistics. The project also demonstrates form validation and browser-based storage.

❤️

Our Vision

LifeDrop aims to promote awareness about voluntary blood donation and demonstrate how digital tools can organize information. A future production version could connect authorized users and licensed blood banks through a secure, verified system.

WHAT THE PROJECT OFFERS

Key Features

Explore the main modules included in this demonstration.

01 / REGISTRATION

Donor Registration

A form to enter sample donor details, select a blood group, and save a registration in browser storage.

02 / SEARCH

Find a Donor

Filter locally saved demo records by blood group and city.

03 / REQUESTS

Blood Requests

Submit fictional blood requests and display their demonstration status.

04 / ANALYTICS

Dashboard

Display donor counts, blood-group distribution, and request statistics.

05 / RECORDS

Donation History

Add, view, and delete fictional donation history records.

06 / DESIGN

Responsive Interface

Provide a red-and-white interface that adapts to desktop, tablet, and mobile screens.

BUILT WITH WEB TECHNOLOGIES

Technology Stack

No backend or paid API is required for this prototype.

HTML5

Page structure and forms

CSS3

Styling and responsive layouts

JavaScript

Validation, search and logic

LocalStorage

Browser-based demo records

Project limitation: LifeDrop is an educational prototype. Its records are stored only in the current browser and are not shared with hospitals or other users. It does not verify donors, confirm blood availability, determine medical eligibility, or arrange blood transfusions. Actual blood requests must be handled through qualified medical services and licensed blood banks.
